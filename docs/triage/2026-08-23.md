## 3. The `polish-target` label gap, fourth week running

Five issues (#48, #49, #50, #51, #52) carry a correct domain label and **no type label**, because
none of the seven permitted types — `skill-bug`, `reviewer-finding`, `description-quality`,
`new-skill`, `docs`, `ci`, `chain-break` — describes *scheduled maintenance on a healthy skill*.
Confidence that any of them applies is well under the 80% bar, so nothing was applied.

This is not a triage failure; it is an unmade taxonomy decision, and it compounds: PLAN mode mints
3–5 such issues every Monday. The blocked count has gone 2 → 3 → 5 over three weeks.

Two options, both one human decision:

1. **Add a `polish-target` (or `maintenance`) label** and let PLAN apply it at creation. Fixes it permanently.
2. **Accept that `weekly-target` is the type label** for these — it already functions as one — and
   drop the requirement for a second type. Zero new labels, but conflates schedule with kind.
